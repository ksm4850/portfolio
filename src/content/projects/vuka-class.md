# 뷰카클래스 — 미용 인터넷 강의 플랫폼

## 개요

뷰카 앱 안에서 미용 인터넷 강의를 수강할 수 있는 서비스입니다.
앱(Flutter)을 제외한 백엔드·웹 프론트·관리자 페이지를 초기 설계부터 개발, 배포까지 혼자 담당했습니다.

- 팀 구성: 백엔드·웹 프론트 1명(본인), 앱 1명, 퍼블리싱 1명, 기획 1명

## 주요 작업

### 강의 API 개발

- FastAPI 기반으로 앱 내 클래스 관련 API 개발 (DB: MSSQL, PostgreSQL)
- 비메오(Vimeo) API를 이용한 강의 영상 처리 (웹뷰)

### 관리자 페이지 개발

- Svelte(프론트) + FastAPI(백엔드)로 관리자 페이지 개발
- 앱에 표시될 강좌·카테고리·배너 관리, 고객 대상 문자/알림톡/푸시 발송 기능

### 인앱결제

- 구글/애플 인앱결제 영수증 검증 후 자사 서비스와 연동
- 문서 기반으로 구조를 파악해 개발부터 테스트까지 안정적으로 마무리

## 배운 점

git init부터 배포까지 프로젝트 전체 사이클을 처음으로 혼자 진행한 프로젝트였습니다.
인앱결제, 비메오 영상, AWS S3, Slack 등 다양한 서드파티를 연동해볼 수 있었고,
처음 써보는 프론트 프레임워크(Svelte)도 기존에 익숙하던 서버 사이드 템플릿 방식과
구조가 유사해 빠르게 적응해서 개발을 완료했습니다.
