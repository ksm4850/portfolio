# 뷰카(VUKA) 앱 API 개발 및 유지보수

## 개요

뷰카는 미용인을 위한 CRM, 미용마켓(B2B 커머스), 클래스(온라인 강의)를 한 곳에서 제공하는 서비스입니다.
Classic ASP 기반의 레거시 API 서버를 운영하면서, 이를 Python(FastAPI) 기반으로 마이그레이션하고 신규 기능을 개발했습니다.

- 팀 구성: 백엔드 2명(본인 포함), 앱 2명, 기획 1명

## 주요 작업

### API 마이그레이션 (Classic ASP → FastAPI)

- Classic ASP + IIS 환경의 API 서버를 FastAPI + Ubuntu 환경으로 마이그레이션 (작업자 2명)
- DB는 MSSQL을 유지하면서 PostgreSQL을 함께 사용하는 구조로 전환
- 마이그레이션과 함께 인프라를 AWS(ECS, RDS, S3)로 이전

### 본인인증 도입 및 계정 통합

- 기존에는 전화번호만으로 회원을 식별해서, 번호가 중복되면 동일 고객인지 판단할 수 없는 문제가 있었음
- 나이스 본인인증을 도입하고, 인증 CI값 기준으로 흩어져 있던 계정을 통합
- 자사몰(뷰카마켓)에 나이스 간편결제 개발

### 소셜 로그인

- 카카오, 애플 간편 로그인 개발

### 앱 기능 개발 및 레거시 유지보수

- Classic ASP, jQuery로 개발된 레거시 어드민/앱 페이지의 추가 기능 개발
- 신규 기능은 FastAPI 기반 API로 개발

## 배운 점

CRM, 커머스, 온라인 강의까지 성격이 다른 여러 서비스를 한 프로젝트에서 개발해볼 수 있었습니다.
마이그레이션을 진행하면서 중복 코드가 쌓이고 프로젝트가 복잡해지는 과정을 직접 겪었고,
초기 프로젝트 구성과 설계가 왜 중요한지 체감하면서 설계와 아키텍처를 더 공부하게 된 계기가 됐습니다.
