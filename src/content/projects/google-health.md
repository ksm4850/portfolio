# Google Health API 기반 건강데이터 수집

## 개요

간호 연구 대상자가 착용한 웨어러블 기기의 건강데이터를 Google Health API로 수집·저장하고,
대시보드와 엑셀로 조회·내보내는 백엔드입니다. 연구자가 대상자별 심박수·활동량·수면 등을
기간별로 확인할 수 있습니다.

- 스택: Python 3.12, FastAPI, SQLAlchemy 2(async), PostgreSQL, Keycloak, APScheduler
- 담당: 백엔드 전반 (연동·수집·조회·엑셀 export)

## 주요 작업

- **Google OAuth 연동** — 서버사이드 authorization code 방식으로 대상자 계정을 연동하고,
  액세스·리프레시 토큰을 관리
- **수집 자동화** — APScheduler 크론으로 매시·매일 수집을 자동화
- **데이터 저장** — `(대상자, 날짜, dataType)` 단위 KV 테이블에 payload를 JSONB로 저장.
  시계열은 1분 단위(rollUp)로 수집
- **조회·export** — 대시보드용 일별 조회 API(분단위 시계열 옵션)와 엑셀 export 개발
- **소급 백필** — 기기를 뒤늦게 연동하거나 재연결한 경우, 과거 구간을 소급 수집

## 수집 구조

Google Health는 데이터를 직접 조회해 가져와야 하는 구조라, 크론 폴링으로 수집합니다.

- **매시 정각** — 연동된 전체 대상자의 오늘치를 전부 다시 받아 덮어씀
- **매일 04:00 KST** — 완료된 어제를 최종 확정. 최근 2일을 겹쳐 훑어 매시 잡이 놓친 구멍을 메움

증분 병합 대신 통째로 덮어쓰는 방식을 택한 이유는, 오늘치 데이터가 하루 안에서는
append-only라 전체를 다시 받아 덮어써도 항상 완전한 하루가 되기 때문입니다. 병합 로직이
필요 없고, 한 번 실패해도 다음 틱에 저절로 복구됩니다.
