# 이미지 라벨링 서비스 — 개발 및 온프레미스 배포

## 개요

라벨링 작업을 하면 자동으로 AI 모델이 학습되는 라벨링 플랫폼입니다.
입사 후 전임자가 개발하던 서비스를 이어받아, 백엔드 개발과 인프라 구축·운영 전반을 담당했습니다.

## 주요 기능

- **2D 이미지 라벨링** — Detection, Segmentation
- **스마트 라벨링** — 이미지에서 객체를 선택하면 자동으로 라벨링 (모델 학습 전에도 기본 객체탐지 지원)
- **오토 라벨링** — 학습된 모델로 이미지 내 클래스별 객체를 자동 탐지
- **파일 드라이브** — 데이터셋 업로드/다운로드, 라벨링 데이터 export
