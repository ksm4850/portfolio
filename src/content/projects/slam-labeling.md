# 이미지 라벨링 서비스 - 개발 및 온프레미스 배포

## 개요

라벨링 작업을 하면 자동으로 AI 모델이 학습되는 라벨링 플랫폼

- 입사 후 전임자가 개발하던 서비스를 이어받아, 백엔드 개발과 인프라 구축·운영 전반 담당

## 주요 기능

- **2D 이미지 라벨링** - Detection, Segmentation
- **3D 메시 라벨링** - STL·OBJ·GLB 메시를 면 단위로 라벨링, 클래스별 메시를 잘라 원본·라벨과 함께 ZIP으로 스트리밍 내보내기
- **스마트 라벨링** - 이미지에서 객체를 선택하면 자동으로 라벨링 (모델 학습 전에도 기본 객체탐지 지원)
- **오토 라벨링** - 학습된 모델로 이미지 내 클래스별 객체를 자동 탐지
- **메모리 뱅크 기반 자동 라벨링(온프레미스)** - 확정 라벨을 메모리 뱅크와 비교해 자동 판정, BE 연동·캐싱·배포 담당
- **파일 드라이브** - 데이터셋 업로드/다운로드, 라벨링 데이터 export
